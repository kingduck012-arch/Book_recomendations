# Book_recomendations
test book recommendations webpage tadokoro-manga
This project is a manga recommendation website for "Tadokoro-san, Volume 1" by TATSUBON.

The website was created for educational and practice purposes, with the aim of practicing web design and development using HTML, CSS, Bootstrap, and JavaScript.

Purpose
Practice HTML, CSS, Bootstrap, and JavaScript
Practice responsive web design
Learn how to structure and design a simple website
Create a manga recommendation page as a learning project
